## Dashboard วิเคราะห์โครงสร้างประชากรและผลกระทบเชิงเศรษฐกิจของสังคมสูงวัยไทย (5 หน้า: Overview, Birth Trends, Regional, Socio-Economic, What-If Simulator)
คำถาม:
1. ประเทศไทยเข้าสู่สังคมผู้สูงอายุแล้วกี่เปอร์เซ็น
2. จำนวนเด็กเกิดใหม่ในแต่ละปีลดลงมากน้อยแค่ไหน
3. จังหวัดใดมีผู้สูงอายุมากที่สุดและจังหวัดใดมีอัตราการเกิดใหม่น้อยที่สุด
4. สัดส่วนแรงงานต่อผู้สูงอายุและงบประมาณเบี่ยผู้สูงอายุและค่าใช้จ่ายสุขภาพภาครัฐมีแนวโน้มอย่างไร
5. หากมีการเพิ่มนโยบายช่วยเหลืออัตราการเกิดใหม่จะเพิ่มขึ้นหรือไม่
## สิ่งที่ได้จากDashboard 
ไทยได้เข้าสู่การเป็นสังคมผู้สูงอายุแล้วและประมาณปี 2576 จะเข้าขั้นวิกฤต
สาเหตุหลักคือเด็กเกิดน้อยลงอย่างต่อเนื่อง จาก 736,352 เหลือเพียง 416,574 ในเวลา 10 ปี ตั้งแต่ปี 2564 มีผู้เสียชีวิตมากกว่าเด็กเกิดใหม่ แต่ไม่ใช่ทุกภาคในประเทศไทยที่จะได้รับผลกระทบ เช่นในภาคเหนือตอนบนและสิงห์บุรีเป็นสังคมผู้สูงวัยขั้นวิกฤตแล้ว ขณะที่สามจังหวัดชายแดนยังไม่เข้าสังคมผู้สูงอายุเลย เมื่อเด็กเกิดน้อย แรงงานก็จะน้อยลงตาม ทำให้ภาระแรงงานเพิ่มขึ้นเท่าตัวจาก 17.5 เป็น 34.1 งบประมาณสวัสดิการจะเพิ่มตามจำนวนผู้สูงอายุเรื่อย ๆ และหากรัฐมีนโยบายสนับสนุนการมีบุตรจะเป็นการแก้ปัญหาในระยะยาว ส่วนการนำเข้าแรงงานต่างด้าวจะเป็นการแก้ปัญหาระยะสั้น จึงต้องใช้ควบคู่กัน
