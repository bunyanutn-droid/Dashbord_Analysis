# Thailand Aging Society Dashboard

Dashboard วิเคราะห์โครงสร้างประชากรและผลกระทบเชิงเศรษฐกิจของสังคมสูงวัยไทย (5 หน้า: Overview, Birth Trends, Regional, Socio-Economic, What-If Simulator)

- เปิดดู: `dashboard.html` (ข้อมูลฝังในไฟล์แล้ว)
- สร้างใหม่: `python build_data.py` (ต้องมี numpy; ดาวน์โหลดไฟล์ดิบด้วย `data/dl.sh`)

## แหล่งข้อมูล
- ประชากรรายจังหวัดแยกอายุ/เพศ ธ.ค. 2543-2568 และจำนวนเกิด-ตาย: ระบบสถิติทางการทะเบียน กรมการปกครอง
- GPP ต่อหัว ปี 2562: สศช.
- ขอบเขตจังหวัด: chingchai/OpenGISData-Thailand

## ข้อจำกัด
เป็นประชากรตามทะเบียนราษฎร์; TFR/CBR และการคาดการณ์เป็นค่าประมาณ; ค่าใช้จ่ายสุขภาพเป็นสมมติฐานที่ปรับได้
